# Add your own evidence here

Assistant-executed portable replay evidence is in automated-replay/. It validates
local failure and recovery behavior, not your independent troubleshooting or the
Docker/AWS deployment exercises. After personally running an exercise, create
`LAB-001.md` using the ticket template and include sanitized command output.
Optional screenshots should show symptoms and verification, not credentials.

Keep public IPs, account IDs, ARNs with account details, private hostnames, customer
information, keys, and tokens out of public evidence. Preserve error codes and
reasoning. Put private notes in evidence/private/ (ignored by Git).

Suggested portfolio evidence:
- At least three independently investigated incidents with actual timestamps.
- One customer-facing knowledge-base article.
- One short narrated demonstration explaining competing hypotheses and verification.
- Your GitHub Actions run showing full Compose incident and recovery checks.

Do not use the fictional sample ticket as your own completed evidence.
